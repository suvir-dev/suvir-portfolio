# King's Labs Academy · Week 1

Your portfolio so far: a Navbar and a Hero, built with React + Tailwind CSS.

## Run it

1. Unzip this folder (right-click → Extract All on Windows, or double-click on Mac).
2. In VS Code: File → Open Folder → pick the `my-portfolio` folder.
3. Terminal → New Terminal, then type:

```
npm install
npm run dev
```

4. Ctrl+click (Cmd+click on Mac) the `http://localhost:5173` link.

## Where things are

- `src/App.jsx`: the page. It puts the Navbar and Hero together.
- `src/components/Navbar.jsx`: your name and the links at the top.
- `src/components/Hero.jsx`: the big first screen.
- `src/index.css`: loads Tailwind.
- `vite.config.js`: switches Tailwind on.

Change "Ana" to your own name, write your own intro, and swap `purple` for your own colour.
